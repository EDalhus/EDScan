# ED Scan

A modern, easy-to-use macOS scanning app for Nikon Coolscan film scanners. Built on [CoolscanKit](https://github.com/EDalhus/CoolscanKit), the scanner core shared with [OpenCoolscan](https://github.com/EDalhus/OpenCoolscan).

> Work in progress. Not affiliated with Nikon Corporation.

## Build

```bash
./build.sh
open "ED Scan.app"
```

Requires macOS 13+. Real scanners need `brew install sane-backends`; choose **Simulated Scanner** to try it without hardware.
